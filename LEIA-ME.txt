CEEJA • MindAR Pong v0.2

Arquivos:
- index.html = página principal
- pong.sb3 = projeto Scratch local
- pong-capa.jpg = imagem de referência da capa
- targets.mind = VOCÊ deve colocar aqui o arquivo compilado no Image Targets Compiler

Como publicar:
1. Publique todos os arquivos na mesma pasta do GitHub Pages / Netlify.
2. Garanta que o arquivo targets.mind esteja no mesmo nível do index.html.
3. Abra o site no celular e permita o uso da câmera.
4. Aponte para a capa do PONG.
5. Quando o jogo aparecer, arraste o dedo sobre o jogo para mover a raquete.

Observação:
- Esta versão usa a própria capa como alvo (sem marcador preto).
- O botão VR foi ocultado.
